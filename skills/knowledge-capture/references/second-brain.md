# Capture into a configured destination

Invoke knowledge-tool-connect to resolve the selected connection/default. Missing setup retains the supplied material and asks only for missing choices, then resumes here. Explicit provider, workspace and target choices are reused; none returns an unsaved proposal. Invalid configuration requires repair.

Pass remote operations to knowledge-tool-connect, including capability checks before credential setup, missing-plugin options and MCP-limit recovery. If the user chooses API, retain content and destination; that choice need not alter the default. Markdown uses the local adapter. No mandatory categories, statuses or confidence fields.

## Material and operation

Use supplied notes, transcripts or other material as requested. Preserve the full content when asked to copy/archive it; summarize or extract only when requested. Do not convert an ordinary note into tasks, deals or ideas automatically. External source gathering needs the requested sources/time scope and does not authorize source mutation.

Determine whether to create, append or update from the request and existing destination conventions. Inspect the actual target schema or document structure. Do not invent owners, dates, labels, commitments or fields. Do not create a schema or reorganize the collection unless requested.

Match relevant existing content before a potentially duplicate create. Read sufficient scoped candidates and preserve stable identities; incomplete reads cannot establish absence. For append/update, freshly read the target and preserve unrelated content. If the target or matching is ambiguous, ask only the unresolved question.

After writing, separately read back target identity and intended content. If a transport failed after a possible write, inspect the existing identity/candidates before retrying through another transport. An unsupported API operation remains a limitation even when a token is configured.

## Receipt

Report verified saves with destination and record/file identity, distinguish unverified attempts and unsaved proposals, and disclose missing access/capability. Do not print private transcript bodies or send to additional destinations without request.
