# Presentation Guidance

Use `bento-slides` for new browser-based presentation decks unless the user chooses another format. Preserve an existing deck's format and use the matching capability for PowerPoint or Google Slides. Bento remains externally managed; keep local editorial preferences here rather than editing its downloaded skill.

## Narrative

- Establish the audience, objective, central claim, evidence, objections, and desired next action before composing slides.
- Build an outline with one clear purpose per slide. Synthesize source material into an argument rather than pasting source notes into the deck.
- Distinguish speaker-led decks, which need sparse text and deliberate pacing, from reading-first decks, which need enough context to stand alone.
- For customer and sales decks, distinguish current product behavior, proposed roadmap, customer-specific diagnosis, and the concrete ask.
- When revising, preserve useful content and the existing structure unless a broader rewrite is requested. Remove examples that do not support the audience's decision.
- Choose visual direction from the subject, audience, and user preferences. Make charts and diagrams explain the evidence or relationships.
- Keep essential information available without hover. Use motion when it clarifies sequence, change, or emphasis.
- Render and inspect the final slides for text fit, hierarchy, legibility, and navigation; check print or export output when requested.
