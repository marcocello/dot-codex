# Knowledge routing

[knowledge-tool-connect](../../skills/knowledge-tool-connect/SKILL.md) owns reusable connections, optional destinations, defaults and preferred transports. Missing setup retains the request, asks only missing choices and resumes. No fixed categories, statuses or directory structure are imposed. Explicit none disables storage.

[knowledge-tool-connect](../../skills/knowledge-tool-connect/SKILL.md) owns capability discovery and ClickUp/Notion MCP/API interactions. It guides missing-plugin installation/connection or supported token access, and offers an explicitly chosen API switch when MCP is limited. It verifies account/workspace and target, reuses credentials and reconciles uncertain writes before retrying. API support is operation-specific, never a guarantee of bypassing limits.

[knowledge-capture](../../skills/knowledge-capture/SKILL.md) owns requested capture and [knowledge-review](../../skills/knowledge-review/SKILL.md) owns read-only review. Explicit local notes and Zotero archives keep their destinations; unrelated work does not require setup. See the [shared contract](../../skills/knowledge-tool-connect/references/secondbrain.md). Existing document paths and optional legacy profile aliases remain for compatibility.
